NOTICEBRIDGE AI / EVALUATION

Independent review workbench

Inspect exact source PDFs, record matching changed passages, and export human review labels. Nothing is sent to a server or an AI model.

1. Load a blank pinned manifest

Use a version-2 blank source or independent reviewer manifest. Do not import another reviewer’s answers or model predictions.

Resuming resets completion and requires both PDFs to be verified again.

2. Select case

Opening a PDF uses your browser’s local PDF viewer. Review the actual printed pages, not the extracted text from NoticeBridge. The fingerprint checks file identity, not official authenticity.

3. Record exact matching passages

Enter the 1-based PDF viewer page numbers (not printed page labels) and exact quotations showing a corresponding change. Do not infer that a missing statement was revoked. If there are no matching changed pairs, leave this section empty after inspecting both PDFs.

4. Export reviewer JSON

A saved workbench draft can contain unfinished quotations and is not an evaluation manifest. Export a finished review only after all cases are complete. Completion is self-declared, not authenticated. Keep the JSON private until reconciled and approved.

Validate the resulting file using the project’s Python review checker. This workbench is not an accuracy evaluator.

Offline reviewer utility · No automatic labeling · No official-authority claims
